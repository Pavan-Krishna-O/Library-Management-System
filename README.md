# 📚 Library Management System

A multi-phase **Library Management System** developed during my internship to gain hands-on experience in backend development, database design, ORM frameworks, ETL workflows, and REST API development.

---

## 📖 Project Overview

This project is divided into three progressive phases, with each phase focusing on a different aspect of backend software development.

The primary objective was to build a robust Library Management System while learning industry-relevant technologies and best practices.

# Phase 1: Database Design & SQL

### Objectives
- Design a relational database for a library system.
- Implement relationships between entities.
- Populate the database with sample data.
- Write SQL queries for common library operations.

### Topics Covered
- Database Design
- Primary & Foreign Keys
- Normalization
- SQL DDL
- SQL DML
- SQL Queries

### Files
- `schema.sql`
- `data.sql`
- `queries.sql`

# Phase 2: SQLAlchemy ETL Pipeline
